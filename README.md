# 🚚 ระบบจัดการคิวรถขนส่งสินค้า (Truck Queue Management System)

ระบบจัดการคิวรถขนส่งสินค้าขึ้นสินค้าที่คลัง ออกแบบมาให้ใช้งานง่าย ไม่ซับซ้อน **ฟรี 100%** ไม่มีค่าใช้จ่าย และไม่ต้องติดตั้ง Library เพิ่มเติม (Zero-dependency)

---

## 📌 โครงสร้างจุดโหลดสินค้า
- **📍 จุดที่ 1 (รถทั่วไป):** สำหรับรถเล็ก (4 ล้อ), รถ 6 ล้อ, รถ 10 ล้อ
  - มีช่องโหลด **3 ช่องพร้อมกัน** (`ช่องโหลด 1`, `ช่องโหลด 2`, `ช่องโหลด 3`)
  - คิวจะขึ้นต้นด้วยตัวอักษร **`A-xxx`** (เช่น `A-001`, `A-002`)
- **📍 จุดที่ 2 (รถเทรลเลอร์):** สำหรับรถเทรลเลอร์ (Trailer) โดยเฉพาะ
  - มีช่องโหลด **1 ช่อง** (`ช่องโหลดเทรลเลอร์ T1`)
  - คิวจะขึ้นต้นด้วยตัวอักษร **`T-xxx`** (เช่น `T-001`, `T-002`)

---

## 🚀 วิธีเปิดใช้งานระบบ
เพียง **ดับเบิลคลิกไฟล์**:
👉 `เปิดระบบคิวรถขนส่ง.bat` (อยู่ที่โฟลเดอร์หลัก)
ระบบจะเปิดเซิร์ฟเวอร์และเปิดหน้าจอใช้งานขึ้นมาให้อัตโนมัติ

---

## 🖥️ หน้าจอหลักของระบบ

| หน้าจอ | ลิงก์เข้าใช้งาน | รายละเอียด |
| :--- | :--- | :--- |
| **📱 หน้าคนขับ (Mobile Ticket)** | `http://<IP-ของเครื่อง>:3000/` | คนขับสแกน QR หน้าคลัง กรอกทะเบียน + เลือกประเภทรถ เพื่อรับบัตรคิวสดบนมือถือ |
| **🖥️ แผงควบคุมเจ้าหน้าที่ (Staff)** | `http://localhost:3000/staff` | จัดการคิว, กดเรียกคิวเข้าช่อง 1-3 หรือเทรลเลอร์, สั่งเริ่มโหลด, สั่งเสร็จสิ้น |
| **📺 จอ TV แสดงผลลานจอด** | `http://localhost:3000/tv` | แสดงสถานะช่องโหลดแบบ Real-time พร้อม**เสียงพูดประกาศภาษาไทยอัตโนมัติ** |
| **🖨️ ป้าย QR Code** | `http://localhost:3000/qr` | หน้าสำหรับพิมพ์ป้าย QR Code (ขนาด A4) ไปติดที่ป้อมยามหรือหน้าทางเข้าคลัง |

---

## ✨ จุดเด่นของระบบ
1. **ไม่ต้องลง Library เพิ่ม:** รันผ่าน Node.js ในเครื่องได้ทันที
2. **Real-time 100%:** อัปเดตข้อมูลทุกหน้าจอทันทีผ่าน Server-Sent Events (SSE) โดยไม่ต้องกดรีเฟรช
3. **ระบบเสียงประกาศภาษาไทย:** จอ TV หน้าลานมีเสียงกระดิ่ง "ติ๊งต่อง" และเสียงพูดภาษาไทยเรียกคิวอัตโนมัติ
4. **เก็บบันทึกข้อมูลลง SQLite ในตัว:** ข้อมูลคิวไม่หายแม้ไฟดับหรือปิดเครื่อง
5. **รองรับมือถือคนขับ:** บัตรคิวจะจำค่าไว้ในมือถือคนขับ เมื่อถึงคิวจะมีสีเขียวแจ้งเตือนชัดเจน
